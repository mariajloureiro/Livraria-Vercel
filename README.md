# 📚 Livraria Web (Deploy Vercel)

Este repositório contém uma aplicação web de livraria desenvolvida como parte das práticas da disciplina de **DevOps / Gerência de Configuração**. O projeto consistiu em reaproveitar um modelo existente, realizar personalizações técnicas e visuais, e realizar o deploy automatizado na plataforma **Vercel**.

---

## 📌 Objetivo do Projeto

* **Clonagem e Gerência de Configuração:** Importação de um modelo/template base existente via repositório Git.
* **Customização e Manutenção:** Alteração e refatoração do código-fonte para adaptação às regras e necessidades da aplicação.
* **Versionamento:** Controle de alterações, registros de commits e publicação no GitHub.
* **Deploy e CI/CD:** Integração contínua e hospedagem automatizada na plataforma Vercel.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** HTML, CSS, JavaScript / React 
* **Gerenciador de Pacotes / Runtime:** Node.js, NPM / NPX
* **Controle de Versão:** Git e GitHub
* **Hospedagem & Deploy Contínuo:** Vercel
